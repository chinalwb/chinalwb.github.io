Softphone embed — Option C (loader script) demo

What this demonstrates: a softphone toolbar embedded via a single <script> line. The loader (embed.js) creates a 52px iframe; when the 拨号盘 (dialpad) opens, the widget measures itself with a ResizeObserver and posts its height to the loader via postMessage, which grows the iframe so the dialpad overlays the page — never clipped, never pushing content down. No height is hardcoded anywhere.

Note: on GitHub Pages everything is served from one origin, so unlike production (widget on the vendor's domain) this demo is same-origin. The code paths are identical — the loader only ever talks to the widget through postMessage, and the widget's origin and URL are derived from the script's own src.

This content sits directly below the softphone toolbar. When the dialpad opens, it should overlay this card (not push it down, not be clipped).

With the dialpad closed, the iframe is only 52px tall, so this button must remain clickable (no invisible click-stealing strip).

More host content, to show the overlay effect clearly. Open the dialpad in the toolbar above and it will cover this card; click any empty area to close it again.
